# CircuitIQ — Project Documentation

> A living document of architectural decisions, evolution, and key context for the CircuitIQ project.

---

## What It Is

A precision web-based circuit design canvas with an AI-backed safety checker. Users wire circuits using a component library, then run an AI-powered check that validates for shorts, reversed polarity, overcurrent, and missing protection.

**Repo:** https://github.com/Tijil-Das/CircuitIQ  
**Live:** *(Cloudflare Pages — URL TBD)*  
**Stack:** Vanilla JS + Vite, Supabase Auth, Cloudflare Workers + D1, Turso

---

## Architecture Overview

```
Frontend (Vite / Vanilla JS)
    ↓  ↑ read-only token
Cloudflare D1         ← Component library (shared, read-only for client)
    
Frontend
    ↓  ↑ Supabase SDK
Supabase Auth         ← Identity only, JWT issuance
    
Frontend
    ↓  Authorization: Bearer <JWT>
Cloudflare Worker     ← All writes: save circuits, run safety checks
    ↓  write token
Turso                 ← Per-user circuits + usage counters
    ↓
AI Provider           ← Safety check AI call (Worker-side only)
```

---

## Key Decisions and Why

| Decision | Rationale |
|---|---|
| Google OAuth only | Reduces auth surface area in v1. No email/password attack vector. |
| GIS SDK ID Token flow | Prevents Supabase domain appearing in Google sign-in prompt |
| Worker-side AI call | AI API keys never exposed to client |
| Supabase for auth only | Turso handles app data — keeps Supabase free-tier friendly |
| Bundled tier-0 components | Zero network dependency for first-time users |
