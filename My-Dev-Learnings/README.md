# Dev Learnings

> *"An expert is someone who has made all the mistakes in a narrow field."* — Niels Bohr

A personal knowledge base of everything I learn while building real projects — written to be recalled, not just recorded.

Each entry is a concept I had to figure out the hard way. It documents the problem, the solution, the exact code, the traps, and how I'd explain it to someone who wasn't there.
