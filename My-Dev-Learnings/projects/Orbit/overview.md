# Orbit — Project Documentation

> A living document of architectural decisions, evolution, and key context for the Orbit project.

---

## What It Is

A personal study command center built as a desktop Electron app. Combines a rich note editor, document viewer, AI assistant, code editor, networking tools, peer-to-peer features, games, and more — all in one offline-first application.

**Repo:** https://github.com/Tijil-Das/Project-Orbit-App  
**Distribution:** GitHub Releases (NSIS installer, auto-update via electron-updater)  
**Stack:** Electron + React 19 + Vite, TipTap editor, Monaco editor, SQLite (better-sqlite3), Supabase Auth, Firebase, Cloudflare Workers, Turso (libsql), Hyperswarm (P2P), Cloudflared (tunnel)

---

## Architecture Overview

```
Renderer (React + Vite)
    ↓  ↑ contextBridge (preload.cjs)
Electron Main Process (Node.js / CJS)
    ├── SQLite (better-sqlite3)       ← Local app data, notes, DB
    ├── Keytar                        ← OS credential store (secrets)
    ├── Cloudflared tunnel            ← Exposes local services remotely
    ├── DNS server (dns2)             ← Local DNS switching
    ├── Hyperswarm                    ← P2P peer discovery + data channels
    ├── Firebase Admin                ← Push notifications
    ├── Google APIs / Drive           ← Drive sync, auth
    ├── Supabase                      ← Auth + networking DB
    └── Cloudflare Workers            ← Edge functions (PDF conversion fallback, etc.)
```

## Key Decisions and Why

| Decision | Rationale |
|---|---|
| Electron (not web) | Needs OS-level access: file system, COM automation, OS keychain, DNS, spawning processes |
| COM automation for PDF conversion | Highest-fidelity Office → PDF using the machine's own licensed Office install; no third-party renderer |
| Cloud fallback for PDF conversion | Users without Office installed still get conversion silently via Cloudflare Worker |
| `better-sqlite3` over remote DB | Offline-first; all notes and data survive without internet |
| `keytar` for secrets | OS credential store is the correct place for API keys/tokens on a desktop app |
| Cloudflared tunnel | Lets the app expose local services (e.g., P2P, sharing) without port forwarding |
| PowerShell `-EncodedCommand` | Avoids Windows path escaping issues when driving COM automation from Node |
