# JioTV Max — Project Documentation

> A living document of architectural decisions, evolution, and key context for the JioTV Max desktop application.

---

## What It Is

A high-performance Windows desktop client for streaming live TV, sports, and entertainment channels. Built with Electron and React, featuring custom frameless glass styling, low-latency HLS/DASH media streaming, channel grid navigation, and seamless Windows 11 system integration.

**Distribution:** NSIS Desktop Installer / Portable Executable  
**Stack:** Electron + React + TypeScript + Tailwind CSS, Native Win32 C++ (Node-API / N-API), HLS.js / Shaka Player, IPC Bridge

---

## Architecture Overview

```
Renderer (React + TypeScript)
    ↓  ↑ contextBridge (preload.ts)
Electron Main Process (Node.js / TypeScript)
    ├── Window Manager           ← Frameless window, titleBarStyle: 'hidden'
    ├── Native Addon (N-API C++) ← Transparent Win32 overlay HWND for DWM Snap Layouts
    ├── Streaming Core           ← Stream decryptor, token refresh, HLS proxy
    ├── Channel Cache            ← Local persistence & favorite channel state
    └── IPC Controller           ← Coordinates bounds, hover states, window commands
```

---

## Key Decisions and Why

| Decision | Rationale |
|---|---|
| Frameless window (`titleBarStyle: 'hidden'`) | Delivers a modern, brand-consistent custom header and caption controls without standard OS chrome |
| Native Win32 Overlay Child HWND | Windows 11 Snap Layouts flyout requires OS `HTMAXBUTTON` hit testing; an HTML button cannot trigger DWM flyouts |
| Node-API (N-API) C++ Addon | ABI-stable across Electron major upgrades without recompiling native code per Electron version |
| Sub-pixel dynamic repositioning via IPC | Synchronizes the transparent child HWND bounds with DOM button layout changes, zoom levels, and DPI scaling |
| Open-source extraction (`electron-win11-snap-overlay`) | Decoupled the overlay mechanism into an isolated, reusable NPM package for any Electron developer facing this Windows 11 limitation |
