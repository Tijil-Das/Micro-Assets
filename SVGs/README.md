## 🎯 Overview

This folder contains two core resources:
1. **Wireboard Web Tools (`wireboardv2.html` & `wireboard.html`):** Standalone, zero-dependency browser tools for interactively laying out circuit boards, dragging microcontrollers and components (Arduino Uno R3, L298N, HC-SR04, servos, LEDs), drawing and routing wires with custom colors, and exporting/importing circuit layouts as JSON.
2. **Curated SVG Assets:** Clean, production-ready vector icons (Changelog, Terms, Privacy, Reviews, Sharing, Phone, etc.) and high-fidelity embedded system wiring diagrams (`Wiring.svg`, `Wiring-flat.svg`).

## 🚀 Tools & Assets

### 1. ⚡ Wireboard (Interactive Circuit Wiring Tool)
- **Path:** [`SVGs/wireboardv2.html`](./wireboardv2.html) | [`SVGs/wireboard.html`](./wireboard.html)
- **What it does:** Drag components onto an interactive canvas grid, connect terminal pins with dynamic bezier/spline wires, color-code connections, and export or load layouts. Runs 100% locally in browser memory without servers or dependencies.
- **How to run:** Double-click or open `wireboardv2.html` in any modern web browser.
